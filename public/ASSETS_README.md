# Press Kit Assets

Place your media assets in the following directories:

## Directory Structure

```
public/
├── images/
│   ├── logo.png              # Game logo (recommended: 512x512 or SVG)
│   ├── hero-bg.jpg           # Hero section background (recommended: 1920x1080)
│   ├── download-bg.jpg       # Download section background (recommended: 1920x1080)
│   ├── og-image.jpg          # Open Graph image for social sharing (1200x630)
│   ├── screenshots/          # Game screenshots
│   │   ├── screenshot1.jpg   # (recommended: 1920x1080)
│   │   ├── screenshot2.jpg
│   │   └── ...
│   ├── team/                 # Team member photos
│   │   ├── john.jpg          # (recommended: 400x400, square)
│   │   ├── jane.jpg
│   │   └── ...
│   └── logos/               # Additional logos, icons
│       └── ...
├── videos/
│   ├── trailer.mp4          # Game trailer
│   └── ...
└── downloads/
    └── press-kit-assets.zip # Downloadable press kit bundle
```

## Recommended Image Sizes

- **Logo**: 512x512px (PNG with transparency) or SVG
- **Hero Background**: 1920x1080px minimum (JPEG)
- **Screenshots**: 1920x1080px (JPEG or PNG)
- **Team Photos**: 400x400px square (JPEG or PNG)
- **OG Image**: 1200x630px (JPEG)
- **Thumbnails**: 640x360px (for video thumbnails)

## Notes

1. Replace placeholder files with your actual assets
2. Use JPEG for photographs and complex images
3. Use PNG for graphics with transparency
4. Optimize images for web to improve load times
5. Keep video files under 100MB for better streaming
